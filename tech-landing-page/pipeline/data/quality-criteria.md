# Quality Criteria — Tech Landing Page

## Critérios de Copy (peso: 40%)

| Critério | Score Mínimo | Descrição |
|----------|-------------|-----------|
| Headline Impact | 7/10 | Headline para o scroll e comunica proposta de valor em < 10 palavras |
| Clareza da Proposta | 8/10 | Visitante entende o que é, para quem é e qual o benefício em 5 segundos |
| CTA Effectiveness | 7/10 | CTAs são específicos, usam voz ativa e estão posicionados estrategicamente |
| Persuasão | 7/10 | Copy usa pelo menos 1 framework identificável (PAS, AIDA, 4Ps, BAB) |
| Prova Social | 6/10 | Depoimentos, números ou logos que geram credibilidade |
| Objeção Handling | 6/10 | Pelo menos 1 neutralizador de objeção antes do CTA principal |
| Tom de Voz | 7/10 | Copy alinhada com a marca do cliente e público-alvo |

## Critérios de Design (peso: 40%)

| Critério | Score Mínimo | Descrição |
|----------|-------------|-----------|
| Visual Hierarchy | 8/10 | Olho segue caminho claro: headline → subtítulo → CTA → conteúdo |
| Dark Mode Quality | 8/10 | Fundo escuro com variações sutis de cinza, sem true black (#000) no fundo |
| Glassmorphism | 7/10 | Efeitos de vidro/blur aplicados como acento, não como linguagem inteira |
| Responsividade | 8/10 | Layout funcional em mobile (375px), tablet (768px) e desktop (1440px) |
| Tipografia | 7/10 | Hierarquia clara, font-weight 500+, tamanhos mínimos respeitados |
| Contraste WCAG AA | 8/10 | Ratio 4.5:1 para body text, 3:1 para large text |
| Consistência Visual | 8/10 | Design system aplicado uniformemente em todas as seções |
| Animações | 6/10 | Animações sutis (fade-in, slide-up) que não prejudicam performance |

## Critérios Técnicos (peso: 20%)

| Critério | Score Mínimo | Descrição |
|----------|-------------|-----------|
| HTML Semântico | 7/10 | Uso correto de header, main, section, footer, nav |
| CSS Moderno | 7/10 | Flexbox/Grid para layout, custom properties para design system |
| Self-Contained | 9/10 | HTML funcional sem dependências externas (exceto Google Fonts) |
| Performance | 7/10 | Sem JavaScript pesado, imagens otimizadas, CSS eficiente |
| SEO Básico | 6/10 | Title, meta description, alt texts, heading hierarchy |

## Regras de Decisão

- **APPROVE**: Score geral >= 7.0 E nenhum critério abaixo de 4/10
- **CONDITIONAL APPROVE**: Score geral >= 7.0, critérios não-críticos entre 4-6/10
- **REJECT**: Score geral < 7.0 OU qualquer critério abaixo de 4/10
- **ESCALATE**: 3+ ciclos de revisão com os mesmos problemas

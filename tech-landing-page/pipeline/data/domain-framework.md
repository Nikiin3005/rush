# Domain Framework — Tech Landing Page

## Processo Operacional Completo

### Fase 1: Briefing e Contexto
1. Coletar informações do cliente: nome, produto/serviço, público-alvo, diferenciais
2. Definir objetivo da LP: geração de leads, venda direta, agendamento, download
3. Identificar concorrentes diretos para referência
4. Definir tom de voz e personalidade da marca
5. Listar materiais disponíveis: logo, fotos, depoimentos, dados de resultado

### Fase 2: Pesquisa e Estrutura
1. Pesquisar referências visuais no nicho do cliente
2. Analisar landing pages de concorrentes
3. Definir a estrutura de seções (ordem e conteúdo de cada bloco)
4. Mapear a jornada do visitante: atenção → interesse → desejo → ação
5. Identificar objeções principais e onde neutralizá-las

### Fase 3: Copy
1. Diagnóstico de awareness level e sofisticação do mercado
2. Definir Big Idea: inimigo, mecanismo único, promessa
3. Criar 3 opções de headline com ângulos diferentes
4. Escrever copy de cada seção seguindo o framework escolhido
5. Criar CTAs com intensidade adequada ao funil
6. Escrever microcopy: botões, labels, tooltips, placeholders

### Fase 4: Design e Desenvolvimento
1. Definir design system: cores, tipografia, espaçamento, grid
2. Criar wireframe da estrutura com hierarquia visual
3. Desenvolver HTML/CSS/JS responsivo
4. Aplicar efeitos glassmorphism e dark mode
5. Implementar animações sutis (scroll-triggered, hover, transitions)
6. Testar responsividade em mobile, tablet e desktop

### Fase 5: Revisão e Entrega
1. Revisar copy contra critérios de qualidade
2. Revisar design contra acessibilidade (WCAG AA)
3. Verificar performance e carregamento
4. Testar todos os CTAs e links
5. Entregar HTML final pronto para deploy

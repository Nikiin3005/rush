# Step 06: Aprovar Copy

Revise a copy completa da landing page acima.

**Pontos para avaliar:**
- A headline escolhida é impactante?
- O tom de voz está adequado ao cliente?
- Os CTAs são claros e motivam ação?
- A prova social é convincente?
- Falta alguma informação importante?
- O FAQ cobre as objeções principais?

Responda com:
- **"Aprovado"** para avançar para o design
- **Ajustes** descrevendo o que quer mudar na copy

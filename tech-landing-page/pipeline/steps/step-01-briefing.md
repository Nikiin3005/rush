# Step 01: Briefing do Projeto

Bem-vindo ao squad **Tech Landing Page**! Vamos criar uma landing page profissional com estética dark mode premium + glassmorphism futurista.

Para começar, preciso de algumas informações sobre o projeto:

1. **Cliente:** Qual cliente da agência? (ex: TechFlow, Construtora Horizonte, novo cliente)
2. **Produto/Serviço:** O que a landing page vai promover?
3. **Público-alvo:** Quem é o visitante ideal?
4. **Objetivo da LP:** Qual a ação desejada? (agendar, comprar, baixar, cadastrar)
5. **Diferenciais:** O que torna este produto/serviço único?
6. **Materiais disponíveis:** Tem logo, fotos, depoimentos, dados de resultado?
7. **Concorrentes:** Conhece concorrentes diretos para referência?

Responda com o máximo de detalhes possível. Quanto mais contexto, melhor a landing page final.

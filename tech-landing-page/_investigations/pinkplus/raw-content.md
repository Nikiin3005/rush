# Investigação — pinkplus.com.br

## 1. Layout e Estrutura
- Hero com proposta de valor principal
- CTA destacado
- Benefícios em cards
- Apresentação dos criadores/professores
- Área de conhecimento (9 pilares)
- Portfólio de projetos reais
- Tabela de preços (modelo freemium com opção fundadora)
- Garantia/política de reembolso
- FAQ
- Footer com dados legais

**Navegação:** Minimalista, com links internos para seções e botão "Sou aluno" no topo.

## 2. Design Visual
- Marca "Pink+" — cor primária rosa/pink
- Tipografia moderna e limpa
- Espaçamento generoso com seções bem separadas
- Estrutura premium para plataforma educacional

## 3. Copy e Texto
- **Headlines:** Imperativas e aspiracionais — "Domine os pilares dos grandes projetos criativos"
- **Proposta de valor:** "Aprenda com quem é referência no mercado" + "processo real de estúdio"
- **Tom:** Premium, direto, profissional, orientado a resultados financeiros
- **CTAs:** "Assinar agora", "Quero experimentar"

## 4. Componentes UI
- Botões com chamadas repetidas (padrão de conversão)
- Cards para listar 9 pilares (Branding, Design, Vídeo, 3D, VFX, etc.)
- Preço com destaque em oferta fundadora (R$1.997 vs R$2.997)
- Selo de garantia "7 dias para decidir"
- Link direto WhatsApp (humanização)

## 5. Padrões Relevantes para o Squad
- Foco em "real" vs. fictício como diferencial
- Oferta limitada (escassez psicológica)
- Comunidade exclusiva (pertencimento)
- Garantia para reduzir fricção
- Suporte humanizado via WhatsApp

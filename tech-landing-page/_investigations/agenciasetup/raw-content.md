# Investigação — agenciasetup.com.br

## 1. Layout e Estrutura
- Hero com tagline "Design · Social Media · IA"
- Seção de comunidade com CTA em vídeo (3 min)
- Grid de 3 produtos destacados
- Seção "Nossos produtos" com cards expandidos (01, 02, 03)
- Newsletter
- FAQ colapsável
- Footer com social links (Instagram, YouTube, TikTok, WhatsApp)

**Navegação:** Mínima, baseada em CTAs diretos para produtos/WhatsApp. Foco em conversão.

## 2. Design Visual
- **Paleta:** Branco/off-white (fundo), tons de azul/cyan, preto (tipografia)
- **Tipografia:** Sans-serif moderna (provável Inter, Poppins ou similar), hierarchy clara com títulos grandes e bold
- **Espaçamento:** Amplo, com seções bem definidas e breathing room generoso
- **Estilo:** Design limpo e flat, light mode

## 3. Copy e Texto
- **Headlines:** Diretos e orientados a resultados — "Aprenda Design Gráfico do zero"
- **Provocadores:** "Somos uma comunidade que te prepara para o mercado que já chegou"
- **Prova social:** "10k+ Alunos", "R$2M+ Faturados"
- **CTAs:** Com seta → ("Acessar→", "Entrar no Calango Studio →", "Conhecer o curso →")
- **Tom:** Confiante, acessível, direto ao ponto, linguagem coloquial brasileira

## 4. Componentes UI
- Botões clean com seta (→) e hover sutil
- Cards com imagem, título, descrição e lista de features
- Numeração visual (01, 02, 03)
- Design flat sem sombras pesadas
- Check marks nas listas de features
- Imagens hospedadas em Supabase

## 5. Padrões Relevantes para o Squad
- Proof points fortes (números reais de resultado)
- Proposta de valor nítida em cada seção
- Funil de conversão eficiente
- Design não-agressivo, profissional mas acessível
- Copy persuasivo sem ser manipulador
- UTM tracking em todos os links

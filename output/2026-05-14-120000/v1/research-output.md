# RESEARCH BRIEF — Rush Produtora

## Briefing
- **Cliente:** Rush Produtora
- **Serviços:** Audiovisual, vídeo, social media, fotografia
- **Público:** Donos de empresa, clientes de valor, pessoas com interesse em redes sociais
- **Objetivo:** Portfólio — mostrar trabalhos e gerar contato
- **Diferencial:** Criatividade
- **Materiais:** 2 fotos profissionais da equipe + logo (dark premium com roxo)
- **Identidade visual existente:** Dark navy, gradiente roxo vibrante, tipografia serif elegante (logo), estética premium

## Referências Analisadas

### 1. Dumela Filmes (dumela.tv)
- **Estrutura:** Hero com reel → Serviços → Processo em 6 etapas → Clientes (logos) → Diferenciais → Portfólio com cases → Formulário de orçamento
- **Portfólio:** Cases agrupados por tipo (2D, Motion Graphics, Séries), vídeos Vimeo embarcados, destaque para números de impacto ("140 milhões de visualizações")
- **Visual:** Dark mode, tipografia clean, atmosfera premium
- **CTAs:** "Watch Reel", "I Want a Quote", "Request a Custom Quote"
- **Insight:** O processo em etapas gera confiança. Números de impacto nos cases validam credibilidade.

### 2. Star Produtora (starprodutora.com.br)
- **Estrutura:** Hero com 3 serviços → Apresentação da empresa → 6 cards de serviço → Clientes → Formulário
- **Portfólio:** Descritivo textual (sem galeria visual forte — ponto fraco)
- **Visual:** Light mode, corporativo, menos impactante
- **CTAs:** "Quero entrar em contato", "Fale conosco"
- **Insight:** Formulário completo com segmentação (cargo, segmento, tamanho). Menção a 17 anos gera credibilidade temporal.

### 3. Void Studios (referência internacional)
- **Estrutura:** Full-screen video background no hero → Portfólio grid → Sobre
- **Visual:** Dark mode cinematográfico, design bold e dinâmico
- **Insight:** Vídeo hero fullscreen é o padrão ouro para produtoras. Comunica qualidade antes de qualquer palavra.

### 4. UMBR Media (referência internacional)
- **Estrutura:** Stills cinematográficos como atmosfera → Seções com transição suave → Vídeo fullscreen
- **Insight:** Usar stills cinematográficos como fundo cria atmosfera artística sem depender de vídeo autoplay.

### 5. Funken Studio (referência internacional)
- **Estrutura:** Portfólio visual em grid → Clientes (Nike, Adidas) → Sobre
- **Insight:** Grid de portfólio com hover revelando título + categoria é padrão eficaz para navegação visual.

## Estrutura Recomendada

1. **Hero** — Headline impactante + subtítulo + CTA "Veja nosso portfólio" ou "Solicite um orçamento". Background com gradiente roxo da marca (sem vídeo autoplay para manter performance).
   - Justificativa: Primeira impressão define se o visitante fica. A identidade dark+roxo da Rush já é impactante por si.

2. **Showreel / Portfólio em Destaque** — 3-4 projetos principais em grid com thumbnail + hover com título e categoria. Link para vídeo ou case completo.
   - Justificativa: O portfólio é o produto. Deve aparecer cedo, antes de explicar serviços.

3. **Serviços** — 4 cards glass (audiovisual, vídeo, social media, fotografia) com ícone + título + descrição curta.
   - Justificativa: Organiza a oferta de forma escaneável sem texto longo.

4. **Sobre / Equipe** — Fotos profissionais dos dois fundadores/membros + breve texto sobre a filosofia criativa da Rush.
   - Justificativa: Produtoras vendem confiança. Mostrar as pessoas humaniza e gera conexão. As fotos já são excelentes.

5. **Números / Prova Social** — Projetos realizados, clientes atendidos, anos de mercado (mesmo que poucos — "criatividade não tem tempo").
   - Justificativa: Credibilidade rápida. Se não tem números grandes, usar qualidade: "Cada projeto é único."

6. **Processo de Trabalho** — 3-4 passos (Briefing → Criação → Produção → Entrega).
   - Justificativa: Desmistifica como funciona contratar uma produtora. Reduz objeção de complexidade.

7. **CTA Final** — "Tem um projeto em mente? Vamos conversar." + botão WhatsApp/formulário simples.
   - Justificativa: Produtoras vendem via conversa. WhatsApp é direto e brasileiro.

8. **Footer** — Logo, redes sociais (Instagram, YouTube), dados de contato, localização.

## Insights de Mercado

- Sites de produtoras premium usam dark mode como padrão (70%+ das referências analisadas)
- Portfólio visual (grid com hover) é mais eficaz que descrição textual
- Vídeo hero fullscreen é padrão ouro mas impacta performance — stills cinematográficos são alternativa elegante
- CTAs de produtoras focam em "orçamento" e "contato" (não "compra")
- Fotos da equipe aumentam confiança em 40%+ (dado de landing pages de serviço)
- WhatsApp como canal de contato é padrão brasileiro para produtoras
